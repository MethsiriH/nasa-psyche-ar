Desktop Calibration Workflow

The mobile learner has been replaced with a Python desktop calibration flow because phone camera tracking was unreliable.

Run Calibration

npm run calibrate:python

Or choose camera index explicitly:

npm run calibrate:python:cam0 npm run calibrate:python:cam1

What this does

  • Uses marker 4 as origin (identity matrix).
  • Flattens table markers 1,3,4,6 to Y=0.
  • Writes output to public/config.json.

Marker settings

  • Matrix type: 3x3 Hamming (6,3)
  • Border size: 0.24 (AR.js patternRatio 0.52)
  • Print size: 2x2 inches
